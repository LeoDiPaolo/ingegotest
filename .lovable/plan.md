# Respecter l’échéance des cartes fragiles

## Correction
- Retirer les cartes fragiles des missions de continuation tant que leur date de révision n’est pas atteinte.
- Conserver leur retour normal via la répétition espacée, notamment le lendemain lorsqu’elles sont dues.
- Lorsqu’aucune nouveauté ou révision n’est due, compléter uniquement avec des cartes déjà acquises, choisies parmi les moins récemment travaillées.

## Vérification
- Confirmer qu’une carte ratée dans une première mission n’apparaît pas dans la mission suivante le même jour.
- Confirmer qu’elle réapparaît lorsque son échéance est atteinte.
- Confirmer qu’il reste possible d’enchaîner plusieurs missions dans une journée.
